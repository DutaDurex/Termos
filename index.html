❓ Panduan TermOS v2

    
Terminal Python modern dengan FakeRoot — powered by Pyodide.

    

      🔓 FakeRoot (BARU!):
      
    
        
  • fakeroot — aktifkan mode root
    • 
        
  • sudo <cmd> — jalankan sebagai root
    • 
        
  • su — masuk root, su user — balik user
    • 
        
  • whoami — tampilkan user aktif
    • 
        
  • id — tampilkan UID/GID
    • 
        
  • apt update / apt install pkg
    • 
        
  • cat /etc/shadow — baca file rahasia
    • 
        
  • exit — keluar dari root
    • 
      

      📁 Shell:
      
    
        
  • ls, ls -la — list file (tersembunyi di root)
    • 
        
  • cd, pwd, mkdir, touch
    • 
        
  • cat, echo, rm, cp, mv
    • 
        
  • tree — tampilkan struktur folder
    • 
      

      🐍 Python:
      
    
        
  • print("halo"), 2+2, import math
    • 
      

      ⌨️ Shortcut:
      
    
        
  • Enter — jalankan
    • 
        
  • Shift+Enter — baris baru
    • 
        
  • ↑ / ↓ — history
    • 
        
  • Ctrl+L — clear
    •
